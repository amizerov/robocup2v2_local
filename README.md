# RoboCup Local Gamemaster

Локальный инструмент для разработки и тестирования стратегий роботофутбола **2 на 2**.

Запустите матч между своими моделями прямо в браузере — без интернета, без регистрации.

---

## Быстрый старт

### Windows

```
start.bat
```

Двойной клик по `start.bat`. Скрипт автоматически:
1. Создаёт виртуальное окружение (`.venv`)
2. Устанавливает зависимости из `requirements.txt`
3. Открывает браузер на `http://127.0.0.1:8080`

> Требуется Python 3.10+. Скачать: https://python.org → «Add Python to PATH» ✓

### Linux / macOS

```bash
chmod +x start.sh
./start.sh
```

Или вручную:

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python server.py
```

## Как написать модель

### Вариант 1 — простой `.py`-файл

Создайте файл в папке `models/` с функцией `get_actions`:

```python
# models/my_strategy.py
import math

def get_actions(observation):
    """
    observation — dict с состоянием матча (описание ниже).
    Вернуть: [[ax1, ay1, kick1], [ax2, ay2, kick2]]
      ax, ay ∈ [-1, 1] — ускорение
      kick   ∈ {0.0, 1.0} — удар
    """
    r0, r1 = observation["my_robots"]
    ball   = observation["ball"]
    bx, by = ball["x"], ball["y"]

    def steer(rx, ry, tx, ty, gain=5.0):
        dx, dy = tx - rx, ty - ry
        d = math.hypot(dx, dy)
        if d < 1: return 0.0, 0.0
        return max(-1.0, min(1.0, dx/d*gain)), max(-1.0, min(1.0, dy/d*gain))

    def kick_ready(r):
        return 1.0 if math.hypot(r["x"]-bx, r["y"]-by) < 55 and r["kick_ready"] > 0.5 else 0.0

    ax0, ay0 = steer(r0["x"], r0["y"], bx, by)
    ax1, ay1 = steer(r1["x"], r1["y"], bx, by)

    return [[ax0, ay0, kick_ready(r0)], [ax1, ay1, kick_ready(r1)]]
```

### Вариант 2 — `.pkl` через cloudpickle

```python
import cloudpickle
```

## Описание `observation`

Параметр `observation` — словарь с полным состоянием матча.  
**Ключевое правило**: ваша команда **всегда атакует вправо** (x → +∞ = ворота соперника).

```python
{
    "my_robots": [
        {
            "x": 320.0,      # горизонтальная позиция, пикс (0 = левый край поля)
            "y": 260.0,      # вертикальная позиция, пикс (0 = верх)
            "vx": 50.0,      # скорость по x, пикс/с
            "vy": -30.0,     # скорость по y, пикс/с
            "angle": 15.0,   # угол поворота, градусы (0 = вправо, ↺ положительный)
            "kick_ready": 1.0  # 1.0 = удар готов, 0.0 = откат ещё не прошёл
        },
        { ... }              # второй робот
    ],
    "opponent_robots": [ { ... }, { ... } ],  # те же поля, зеркально по x

    "ball": {
        "x": 540.0,          # позиция мяча по горизонтали
        "y": 320.0,          # по вертикали
        "vx": 120.0,         # скорость мяча
        "vy": 0.0
    },

    "score": {
        "my":       0,       # ваши голы
        "opponent": 1        # голы соперника
    },

    "time_remaining": 45.3,  # секунд до конца матча
    "period_seconds": 60.0,  # общая длительность

    "field": {
        "x": 0.0, "y": 0.0,
        "width":  1080.0,    # ширина поля в пикселях
        "height": 640.0,     # высота
        "goal_y_top":    210.0,  # верхний край ворот по y
        "goal_y_bottom": 430.0   # нижний край ворот по y
    }
}
```

## Интерфейс приложения

### Вкладка «Матч»

1. Выберите **Команда 1** (жёлтые) и **Команда 2** (синие) из дропдаунов.
2. Настройте **длительность** (ползунок, 10–300 с) и **скорость симуляции**:
   - `Максимум` — результат мгновенно (для тестов)
   - `10×` — ≈6 сек для матча 60 с (удобно наблюдать)
   - `1:1` — реальное время (для дебага)
3. Нажмите **▶ Старт**.
4. Наблюдайте за матчем на поле. После финального свистка появится карточка результата.
5. Нажмите **⬆ Загрузить модель** для добавления новых файлов.

### Вкладка «Таблица»

- **Рейтинг моделей** — W/D/L, голы, очки (3 за победу, 1 за ничью).
- **История матчей** — все сыгранные матчи в хронологическом порядке.
- **Сбросить историю** — удаляет все данные из базы.

### Вкладка «Документация»

Встроенная документация (вы сейчас её читаете в README; в браузере — то же самое).

## Советы

- **Запускайте модель против себя** — выберите одну и ту же модель в обоих дропдаунах, чтобы найти слабые места стратегии.
- **Запускайте модель против себя** — выберите одну и ту же модель в обоих дропдаунах, чтобы проверить симметрию.
- **Длительность 30–60 с** достаточна для большинства тестов; финальный турнир — 180 с.
- Если ваша модель использует `torch`, `stable-baselines3` и т.д., установите их вручную:  
  ```bash
  pip install torch stable-baselines3 scikit-learn
  ```
- Все результаты сохраняются в `leaderboard.db` (SQLite) между запусками.

## FAQ

**Модель не загружается / ошибка при старте матча**  
Проверьте, что в `.pkl`-файле есть метод `get_actions(observation)`, а все нужные библиотеки установлены в venv.

**Браузер открывается, но поле пустое**  
Дождитесь, пока сервер полностью стартует (1–2 сек), затем обновите страницу.

**Хочу добавить свою базовую модель в список по умолчанию**  
Положите `.py` или `.pkl` файл в папку `models/` до запуска (или загрузите через интерфейс).

**Как сохранить модель, обученную через stable-baselines3?**
